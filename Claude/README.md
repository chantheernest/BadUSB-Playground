# Claude

A scratch / workspace folder for the AI assistant (Claude) working in this
repository.

## Purpose

This folder is a home for AI-assistant artifacts that are **not payloads** and
don't belong under a hardware-platform directory — for example:

- Working notes, analysis, and summaries about the repository.
- Drafts and scratch files generated while researching or refactoring.
- Documentation or indexes produced to help navigate the payload tree.

## What does NOT go here

- **Payloads.** Those belong in their platform/category directory
  (`Ducky/`, `BashBunny/`, `OMG/`, `WHID/`, `Malduino/`) per the conventions in
  the root `CLAUDE.md`. Do not stage payloads here to bypass naming/placement
  rules.

## Conventions

- No spaces in file or directory names (use `-` or `_`), matching the rest of
  the repo.
- Anything worth keeping must be committed and pushed — the working environment
  is ephemeral.
